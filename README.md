# SeaWraps blog images

Featured images for the [SeaWraps](https://seawrapco.com) blog, generated by the
daily blog job in the private `seawraps/SeaWraps` repository.

They live here, in public, for one reason: WordPress posts need a stable image
URL, and every other option leaks. Uploading to `/wp-content/uploads/` does not
survive a Local → WP Engine push, which mirrors the whole `wp-content/` tree and
deletes anything not present locally. Hotlinking a stock photo library brings
back the reused-image problem these replaced.

Images are served through jsDelivr, pinned to the commit that added them:

    https://cdn.jsdelivr.net/gh/seawraps/blog-images@<sha>/<post-slug>.jpg

Pinning to a SHA rather than a branch means the URL is immutable and cached
permanently, so a new file is reachable the moment it is pushed.

Do not edit files here by hand: the post that references an image points at the
commit it was added in, so later edits to a file will not appear on the site.
Nothing here is a dependency of the theme, and nothing reads from this repo at
build time.
